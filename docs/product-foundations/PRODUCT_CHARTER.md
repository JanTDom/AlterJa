# Karta produktu Alterja (alterja.pl)

## 1. Misja i definicja produktu
Alterja to system tworzący kontrolowany przez właściciela, rozwijający się cyfrowy model jego osoby: pamięci autobiograficznej, sposobu wypowiadania się, preferencji, wartości deklarowanych i ujawnianych w wyborach, wiedzy oraz reakcji w określonym kontekście.
Model potrafi precyzyjnie wskazać, na jakich materiałach opiera odpowiedź, oraz otwarcie przyznać, czego nie wie.

## 2. Trzy filary zastosowania
1. **Prywatny asystent osobisty:** System dogłębnie znający użytkownika, jego styl pracy, kontekst życiowy i cele, pomagający w podejmowaniu decyzji i redagowaniu myśli bez konieczności ciągłego tłumaczenia kontekstu od nowa.
2. **Platforma API zdolności:** Kontrolowane udostępnianie wybranych kompetencji, fragmentów pamięci lub stylu zewnętrznym aplikacjom (np. narzędzia edytorskie, systemy planowania) w oparciu o granularne uprawnienia, bez oddawania całej tożsamości.
3. **Cyfrowa spuścizna:** Bezpieczne zachowanie autentycznego archiwum życiowego oraz możliwość kontaktu z wyraźnie oznaczoną rekonstrukcją AI po śmierci właściciela, wyłącznie na podstawie uprzednich dyspozycji i za obopólną zgodą odbiorców.

## 3. Granice pojęciowe i etyczne
- **Pojęcie „cyfrowej nieśmiertelności”:** Jest to metafora i nazwa idei kulturowej, a nie obietnica biologicznego czy metafizycznego przeniesienia świadomości.
- **Zakaz symulacji świadomości:** Model nie przeżywa emocji, nie odczuwa cierpienia ani radości. Odtwarza wzorce zachowań i stylu na podstawie materiału dowodowego.
- **Zakaz podszywania się:** System nigdy nie udaje biologicznej osoby ani nie przedstawia generowanych zdań jako jej dosłownych, autentycznych słów z przeszłości.
- **Niezależność użytkowników:** Alterja jest platformą wielodostępną dla wielu niezależnych użytkowników; nie jest zaszytym na stałe profilem jednej konkretnej osoby.
- **Brak wiążących skutków prawnych:** Model nie może składać oświadczeń woli, sporządzać testamentu ani podejmować zobowiązań majątkowych w imieniu człowieka.
